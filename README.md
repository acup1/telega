# telega

Лицензия: [GNU GPL v3](LICENSE) (`GPL-3.0-only`).

Полноэкранный Telegram-клиент для терминала на Rust и
[`terminalib`](https://github.com/acup1/terminalib). Работает с обычным
пользовательским аккаунтом через MTProto (`grammers`), а не через Bot API.

## Возможности

- минималистичная Telegram-подобная раскладка: скруглённые панели чатов и
  переписки, сообщения без обводки, папки отдельной вертикальной колонкой слева;
- кликабельные hitbox-области чатов, сообщений, медиавложений и строки ввода,
  независимая прокрутка списка чатов и переписки колёсиком мыши;
- профиль по клику на имя/аватар в шапке: описание, большой аватар, вкладки
  фото/видео, файлов, музыки, голосовых, ссылок и закрепов; закреплённые истории
  («Posts / Stories») и подарки («Gifts») открываются из профиля;
- поиск слева объединяет свои диалоги с серверными результатами пользователей,
  групп и каналов; клик по `@nick` в сообщении открывает его диалог;
- закрепы под шапкой: переход к старому сообщению с контекстом, полный список
  через `[list]`/`p`, закрепление и открепление в меню сообщения;
- постраничная загрузка всей истории; в ленте сначала скачиваются только
  Telegram-миниатюры фото и видео, полный файл — лишь при открытии;
- Telegram-альбомы объединяются в одно сообщение, но каждый элемент остаётся
  отдельно кликабельным;
- отправка текста без полной перезагрузки истории и отметка прочитанного;
- меню `📎`: фото/видео, файл в исходном качестве и аудио; выбор через встроенный
  файловый браузер или ввод пути, затем явная отправка;
- комментарии каналов с текстом и вложениями; связанный чат можно читать без
  вступления в группу (`c` — ветка, `g` — связанный чат);
- фото, web-preview, PNG/JPEG/WEBP и inline-стикеры через встроенный в
  `terminalib` Kitty Terminal Graphics Protocol (TGP), с сохранением пропорций;
- WEBP-, TGS- и WEBM-стикеры показываются и анимируются прямо в сообщении;
- custom emoji загружаются по entity и рисуются через TGP прямо в строке;
- аватарки списка чатов круглые; фото в шапке, профиле и галерее сохраняют исходный вид;
- истории показываются над папкой «Все чаты» и листаются колесом мыши; полный
  список открывается клавишей `s` без открытого чата или кнопкой `+`;
- меню `🙂` / `Ctrl+E`: обычные эмодзи, недавние и установленные стикеры,
  установленные и рекомендуемые custom emoji, анимированные превью и мышь;
- блоки кода с непрозрачным фоном, сохранением отступов, подсветкой указанного
  языка и кнопкой Copy; `md`/`markdown` рендерится, `latex` — читаемой текстовой формулой;
- полноэкранное медиа открывается по центру на верхнем TGP-слое; `←/→`
  подгружают соседнее изображение напрямую из истории, даже если эта часть чата
  ещё не открывалась;
- видео, GIF/WEBM и кружки начинают воспроизводиться из Telegram-чанков
  через HTTP Range; `ffmpeg` декодирует сменяющиеся TGP-кадры, а звук идёт через
  доступный `mpv` или `ffplay`;
- GIF автоматически повторяются в видимых сообщениях, кружки запускаются по
  клику и воспроизводятся в сообщении с круговой маской, а не на весь экран;
- голосовые и музыка управляются отдельным плеером в сообщении: пауза и
  перемотка доступны мышью, одновременно играет только одно аудио;
- кружок при воспроизведении увеличивается внутри ленты, после окончания
  возвращается к обычному размеру; звук кружка не пересекается с голосовыми;
- реакции показываются под сообщениями; ПКМ по сообщению открывает выбор
  реакции и действия «ответить», «копировать», «переслать» и «удалить»;
- двойной ЛКМ активирует Reply; удаление подтверждается отдельно с выбором
  «у себя» / «у всех» (для каналов и супергрупп — удаление у всех при наличии прав);
- входящие сообщения, редактирования, удаления и реакции поступают через поток
  MTProto, без ручного обновления и сброса позиции прокрутки;
- настройки открываются отдельным окном с вертикальным списком разделов по шестерёнке внизу колонки папок;
- повторный клик снимает свою реакцию, All reactions открывает полный разрешённый
  каталог с прокруткой и установленными emoji-наборами; custom/premium emoji
  рисуются через TGP, лимит реакций берётся из Telegram appConfig;
- у исходящих сообщений: ✓ — приняты Telegram, ✓✓ — прочитаны; статус обновляется
  в фоне, без перезагрузки переписки;
- Unicode/emoji-aware framebuffer корректно обрабатывает широкие и составные
  emoji без артефактов;
- ошибки и вывод медиапроцессов не смешиваются с TUI, журнал находится в
  `TELEGA_CACHE/telega.log`;
- воспроизводимая сборка Nix для Linux и macOS.

По умолчанию используются иконки Nerd Fonts. Выберите соответствующий шрифт
в настройках терминала или отключите значки через меню `m` → Nerd Fonts,
либо задайте `TELEGA_NERD_FONTS=0`.

Для графики нужен терминал с Kitty graphics protocol: Kitty, Ghostty, WezTerm
или свежий Konsole. В другом терминале текстовый интерфейс работает, а на месте
TGP-медиа показывается значок Nerd Font, либо `!`, если Nerd Fonts отключены.
Над картинками нет служебных подписей image/album/loading.

## Установка готового клиента

В готовом клиенте уже есть реквизиты приложения. При первом запуске введите
номер телефона, код от Telegram и пароль двухэтапной аутентификации, если он включён.
При следующих запусках клиент использует сессию из `~/.cache/telega/telega.session`.

После публикации [релиза](https://github.com/acup1/telega/releases) запустить клиент
с медиазависимостями можно одной командой на Linux x86-64, Linux ARM64 и macOS Apple Silicon:

```sh
nix run 'https://github.com/acup1/telega/releases/latest/download/telega-nix.tar.gz'
```

Если вам передали файл `telega-nix.tar.gz`, перейдите в каталог с ним и выполните
`nix run "tarball+file://$PWD/telega-nix.tar.gz"`. Nix выберет сборку для вашей системы.

Без Nix скачайте архив для своей платформы из того же релиза. Например, для Linux x86-64:

```sh
tar -xzf telega-x86_64-linux.tar.gz
./bin/telega
```

Для Apple Silicon нужен `telega-aarch64-darwin.tar.gz`, для Linux ARM64 —
`telega-aarch64-linux.tar.gz`. Для видео и стикеров в обычной установке нужны
`ffmpeg`, `rsvg-convert` и `python3` с модулем `lottie` в `PATH`.
Для звука подходит `mpv`, `ffplay` или системный `afplay`.

## Отдельный просмотрщик фото и видео

`tgp-viewer` открывает локальные файлы в терминале и использует тот же код
отрисовки и воспроизведения, что галерея telega. Для него не нужен аккаунт
Telegram. Скачать архив можно из [релиза просмотрщика](https://github.com/acup1/telega/releases/tag/viewer-v0.1.0%2Bbuild.2).
Для запуска через Nix:

```sh
nix run 'https://github.com/acup1/telega/releases/download/viewer-v0.1.0%2Bbuild.2/tgp-viewer-nix.tar.gz' -- photo.jpg clip.mp4
```

Из исходников используйте `nix run .#tgp-viewer -- photo.jpg clip.mp4`.
В нативном архиве просмотрщика запускайте `./bin/tgp-viewer photo.jpg clip.mp4`.
Стрелки ← и → переключают файлы, Esc закрывает просмотр. Для картинок и кадров
видео нужен терминал с Kitty graphics protocol.

## Сборка из исходников

```sh
git clone https://github.com/acup1/telega.git
cd telega
nix run .
```

Для своей сборки разработчик указывает реквизиты приложения из
[my.telegram.org](https://my.telegram.org) в локальном `api-credentials.env`
(`TG_API_ID=...` и `TG_API_HASH=...`) или в окружении. Файл исключён из Git.
`nix run .` из Git checkout читает его при запуске из текущего каталога.
Обычная сборка Cargo — `cargo build --locked --release`. Для сохранённой
авторизованной сессии достаточно `TG_API_ID`.

## Выпуск готовой сборки

Чтобы собрать архив для своей платформы, задайте пару приложения и выполните
`scripts/package-release.sh`. Архив и его SHA-256 появятся в `target/dist/`.
Режим сборки `bundled-app` проверяет наличие обоих реквизитов.
Встроенный `api_hash` можно извлечь из распространяемого бинарника.

Пара `api_id` и `api_hash` идентифицирует приложение перед Telegram.
Для доступа к переписке требуется ещё авторизация пользователя или его
действующая сессия. Если пара станет общедоступной, другие программы смогут
использовать идентификатор telega, а ограничения на новые входы затронут и
пользователей клиента. Штатного отзыва hash у разработчика нет.
[Авторизация Telegram](https://core.telegram.org/api/auth) ·
[Рекомендации Telethon для авторов приложений](https://docs.telethon.dev/en/v2/basic/signing-in.html).

В [tgt](https://github.com/FedericoBruzzone/tgt/issues/63) пользователи
столкнулись с `API_ID_PUBLISHED_FLOOD`; точную причину Telegram не подтвердил.
В [пакете Telegram Desktop для Arch](https://github.com/telegramdesktop/tdesktop/issues/4717)
та же ошибка блокировала вход при использовании общедоступной тестовой пары.
Для релизов telega используйте собственную пару из Actions Secrets.
Сборщики форков могут использовать свою пару. QR-вход тоже требует оба
значения. [Регистрация приложения](https://core.telegram.org/api/obtaining_api_id) ·
[Вход по QR](https://core.telegram.org/method/auth.exportLoginToken).

Для выпуска на GitHub владелец репозитория задаёт два Actions secrets,
`TG_API_ID` и `TG_API_HASH`, и отправляет тег вида `v0.1.0` на коммит с workflow.
После сборки всех трёх архивов workflow публикует их вместе с Nix-пакетом и
`SHA256SUMS` в одном релизе. Пользователям этого релиза достаточно войти в свой аккаунт.
Тег вида `viewer-v0.1.0` выпускает только просмотрщик и его Nix-пакет
`tgp-viewer-nix.tar.gz`. Для этого тега Actions Secrets не нужны.

## Управление

| Клавиши | Действие |
|---|---|
| `↑` / `↓`, `j` / `k` | выбрать чат или сообщение |
| `Enter` | открыть чат или выбранное медиа |
| `e` / `i` | написать сообщение, если в чате есть право отправки |
| стрелки в поле ввода | переместить курсор; `↑` в первой строке — редактировать последнее своё сообщение |
| `Ctrl+F` в чате | найти сообщения на сервере и перейти к результату |
| `s` / кнопка Stories | смотреть истории открытого чата; `s` без чата — список историй |
| `Enter` в поле ввода | отправить, сохранив фокус ввода |
| `Shift+Enter` | перенос строки в сообщении |
| `a` | открыть меню вложений и файловый браузер |
| `Ctrl+V` | вставить изображение, файлы или текст из системного буфера |
| `Ctrl+E` / кнопка `🙂` | меню эмодзи, стикеров и custom emoji |
| `c` | открыть комментарии выбранного поста канала |
| `g` | открыть связанный чат без вступления |
| `p` | открыть закреплённые сообщения |
| `/` | поиск по чатам |
| `m` / шестерёнка внизу папок | открыть окно настроек поверх приложения |
| `t` | импортировать тему из файла или ссылки Telegram |
| `r` | обновить |
| `Esc` | снять фокус ввода / назад; в «All chats» без открытого чата — выйти |
| `q` | назад / выйти из «All chats» без открытого чата; в поле ввода — обычная буква |
| клик мышью | открыть чат, выбрать пузырёк, открыть медиа или начать ввод |
| колесо мыши | прокрутить чаты или сообщения под указателем |

Цитата над ответом показывает автора и текст исходного сообщения; клик
загружает его контекст. Кнопка `↓ latest` возвращает к концу истории,
даже после перехода к старому сообщению, не стирая набранный черновик.
Она всегда запрашивает последние сообщения с сервера, а не только локальный
конец списка. Внутренняя `☰` над чатами сворачивает список до аватарок;
шестерёнка внизу папок открывает настройки приложения.

Окно настроек имеет разделы Appearance, Media, Folders, Storage, Controls и Language.
`Tab`/`←→` переключают раздел, `↑↓` выбирают пункт, Enter применяет, Esc или клик
снаружи закрывает окно. В Media можно отключить autoplay GIF и анимацию стикеров;
переключатели сохраняются в `~/.cache/telega/preferences`.
В Language можно выбрать язык Telegram Desktop либо ввести код или ссылку
`t.me/setlanguage/...` для своего языкового пакета. Официальные строки интерфейса
берутся из пакета Telegram; собственные подписи клиента имеют английский и
русский варианты. Выбор сохраняется в `~/.cache/telega/language`.
Окно не расширяет свёрнутую панель чатов и не сбрасывает черновик при импорте темы.

После отправки фокус остаётся в поле ввода. Esc выходит из него; если открыто
дочернее меню эмодзи/сообщения, первый Esc закрывает меню, следующий — ввод.
Черновик и ответ сохраняются: `i` или клик по полю возвращают фокус.
Shift+Enter использует расширенный протокол клавиатуры, поддерживаемый Kitty,
Ghostty и другими совместимыми терминалами; старые терминалы могут не отличать
его от Enter. Многострочный черновик занимает до пяти видимых строк.

В меню эмодзи `Tab` переключает вкладки, стрелки выбирают ячейку, Enter вставляет
эмодзи или отправляет стикер; колесо прокручивает сетку, `‹`/`›` переключают наборы.
Кнопка `×` закрывает боковую панель; она остаётся открытой после отправки стикера
и скрывается при выходе из чата. Обычный
стикер отправляется отдельным сообщением; custom emoji вставляется в черновик.
Без Premium платный custom emoji передаётся как обычный emoji с entity-ссылкой
`tg://emoji?id=DOCUMENT_ID`. Этот клиент распознаёт ссылку и анимирует стикер;
остальные клиенты без поддержки формата показывают обычный emoji со ссылкой.
Это совместимый формат, не обход серверной проверки Premium-entity; поддержка
другими неофициальными клиентами зависит от их реализации. Для Premium и
бесплатных custom emoji используется стандартная entity Telegram.

Copy над блоком кода копирует точный исходник через OSC 52 (если это разрешено
настройками терминала), включая отступы и разметку. Без указанного языка нет
названия и подсветки; фон блока остаётся непрозрачным при любой теме.
Блоки `md`/`markdown` показывают заголовки, списки и форматирование вместо
исходных маркеров, с переносами и висячими отступами списков.
`latex`/`tex`/`math` отображаются только текстом: греческие буквы и операторы,
двумерные дроби, корни с показателем, верхние и нижние индексы, матрицы,
биномиальные коэффициенты и черты над или под выражением. Поддерживаются отдельные
формулы, `$...$`, `\[...\]` и обёртка документа. Графический рендер полностью
отключён даже при TGP; внешние процессы для формул не запускаются.

Во время видео `Space` или клик по центральной кнопке под кадром переключает
паузу, `Esc` закрывает плеер. Клик по самому кадру не перехватывает контролы.
Клик и перетаскивание таймлайна перематывают видео к выбранному времени, включая
ещё не загруженные участки. Текст плеера находится на верхнем TGP-слое,
а чат затемняется отдельным полупрозрачным слоем. Полноэкранный
просмотр сразу показывает миниатюру из памяти, а если её
ещё нет, загружает её параллельно с полной картинкой.
В конце видео просмотрщик остаётся открытым: Play/Space запускает повтор,
таймлайн позволяет перемотать назад. При ошибке декодирования он тоже не
закрывается сам, а диагностика остаётся в журнале.

Клик по имени или аватару в шапке открывает правую панель профиля. На узком
экране она занимает область переписки; `Esc`/`×` закрывают её. Колесо над
панелью прокручивает вложения, `Load more` запрашивает следующую страницу.
Файлы сохраняются после ввода пути и Enter; существующий файл не перезаписывается.
Клик по большому аватару в профиле открывает полноэкранную историю фотографий:
`←/→` переключают снимки и догружают следующие страницы Telegram, Esc или клик
по пустому месту закрывает просмотр. Аватары сохраняют исходные пропорции.

Для вставки вложений используйте `Ctrl+V` или `a` → Paste from clipboard.
Поддерживаются изображения из буфера, файлы Finder/URI-списки, текстовые пути,
кавычки и пути с пробелами. Терминальная вставка (`Cmd+V`/`Ctrl+Shift+V`, если
терминал её поддерживает) принимает текст/пути; бинарную картинку следует
вставлять через `Ctrl+V` самого приложения. Буфер читается на машине, где
запущен клиент; через SSH это не переносит файлы с локальной машины автоматически.

В предпросмотре `c` выбирает фото со сжатием, `f` — исходный файл без сжатия,
Enter/Send подтверждает отправку, Esc/Cancel отменяет. Можно вставить несколько
файлов и дополнить очередь ещё одной вставкой. Сжатое фото конвертируется в JPEG
до 2560 px с сохранением пропорций; режим File передаёт исходные байты.
Оригиналы не меняются, временные изображения буфера удаляются после отправки
или отмены. Многострочная вставка не вызывает отправку сообщения автоматически.
В Nix на Linux включены `wl-paste` и `xclip`; при обычной сборке нужен один из них
для Wayland/X11. macOS использует системные средства без дополнительных пакетов.

В меню сообщения доступны All reactions и Remove my reactions. В выборе реакций
колесо/`↑↓` листают список, `<`/`>` переключают установленные custom emoji-наборы.
Повторный клик по собственной реакции снимает её; счётчики других пользователей
не уменьшаются. Сервер проверяет ограничения чата и подписки. Платные Star-реакции
показываются в сообщениях, но не отправляются и не списывают Stars из этого меню.

Custom-реакции доступны для выбора без локальной проверки Premium и отправляются
только нативным `sendReaction`, никогда не отдельным ответом. Если Telegram вернёт
`PREMIUM_ACCOUNT_REQUIRED`, клиент покажет отказ, не создавая сообщений и не
изображая успешную установку. Это не обход серверной проверки подписки.
Старые совместимые emoji-ответы прежней версии читаются и могут быть сняты
повторным кликом; новые такие ответы больше не отправляются.

Сообщения и миниатюры открытого чата хранятся только в памяти и освобождаются
при его закрытии. Полные фото и аудио существуют во временном каталоге только
на время просмотра, а видео идёт в декодеры напрямую из Telegram-чанков.
Постоянно кешируются только аватарки. Все данные
клиента находятся в `~/.cache/telega`: `avatars/`, `telega.session`, временный
`runtime/` и `telega.log`. Корень можно переопределить через `TELEGA_CACHE`,
путь к сессии — через `TELEGA_SESSION`. При необходимости геометрию ячейки
задаёт `TELEGA_CELL_ASPECT`, частоту и ширину видео — `TELEGA_VIDEO_FPS` и
`TELEGA_VIDEO_WIDTH`.

## Темы

В меню `m` доступны Terminal, Classic, Day, Tinted и Night. Terminal сохраняет
прозрачный фон; цветные фоны остальных тем можно отключить переключателем
Background. Клавиша `t` принимает локальный `.tdesktop-theme`,
`.tdesktop-palette` или ссылку `https://t.me/addtheme/...`. Поддерживаются
текстовые палитры и ZIP-архивы с `colors.tdesktop-theme` / `colors.tdesktop-palette`,
цветовые alias и RGB/RGBA-значения. Импортируются цвета элементов интерфейса;
обои и графические эффекты Desktop не используются. Выбор сохраняется под
`~/.cache/telega`. `TELEGA_THEME` позволяет задать тему при запуске.
Клик по `t.me/addtheme/...`, `telegram.me/addtheme/...` или `tg://addtheme?slug=...`
в сообщении (включая скрытые текстовые ссылки) открывает отдельный предпросмотр.
Apply/Enter сохраняет палитру и добавляет/устанавливает тему в аккаунте Telegram;
Cancel/Esc оставляет текущую тему без изменений.

## Безопасность

Встроенные реквизиты приложения можно извлечь из бинарника и Nix store.
Они не заменяют авторизацию пользователя. Файл сессии даёт доступ к аккаунту —
не передавайте его другим людям. Пароль 2FA вводится без эха и не сохраняется.

## Проверка с живой сессией

Необязательный тест выполняет только читающие запросы: список историй с
пагинацией, поиск, публикации и подарки своего профиля, загрузку языкового
пакета. Используйте отдельную копию файла сессии:

```sh
TELEGA_LIVE_SESSION=/путь/к/копии/telega.session cargo test --test live_readonly -- --ignored
```

Для проверки слоёв TGP, мыши и воспроизведения нужен интерактивный терминал;
этот тест их не имитирует.
